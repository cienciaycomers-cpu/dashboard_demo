## Cross-cutting principles

- No artificial deadline; optimize for a clean, verified handoff.
- Keep work in dependency order and limit work in progress to one implementation task at a time.
- Verify each domain layer before binding it to the UI.
- Preserve the option to pause after a demonstrable milestone.
